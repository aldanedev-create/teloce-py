# Teloce-Py documentation

Teloce is the browser component layer; your Python framework remains the application layer.

## Fastest path

Read [Getting started](getting-started.md), create `static/js/App.vel`, add the small `app.py` host shown there, and run:

```bash
python app.py
```

Then open the URL printed by the server. You do not need to manually run a separate JavaScript command for this workflow.
